## ArcSegment 圆弧路段实现

- `src/segments/ArcSegment.ts`：继承 Segment 抽象类
  - 字段：center / radius / startAngle / endAngle / clockwise
  - sweepAngle = length / radius（从里程反推，保证与 endMileage-startMileage 一致）
  - getPointAt(s)：ratio=(s-start)/length → θ=startAngle±ratio×sweep → 坐标/切/法/方位角
  - 顺时针切向：[sin θ, −cos θ]；逆时针切向：[−sin θ, cos θ]
  - 法向量 = 切向量逆时针 90°：[−ty, tx]
  - 方位角 = atan2(tx, ty)（x=东 y=北 测量坐标系）
- `src/segments/index.ts` 追加导出 ArcSegment / ArcSegmentOptions
- TypeScript 编译：0 错误

## queryMileage 里程查询

- `src/alignment/queryMileage.ts`：输入 Segment[] + mileage，用 find 定位路段后调用 getPointAt，找不到返回 null
- `src/App.tsx` 新增查询面板：input 输入里程 + 查询按钮（支持回车），显示 X / Y / 方位角（度），错误提示红色
- TypeScript 编译：0 错误
- 算法：遍历中间 JD，r > 0 时在角处"倒角"生成 Line → Arc → Line，r === 0 时生成 Line
- 圆心 = 角平分线方向 × (R / sin(Δα/2))；切点距 JD 为 T = R × tan(Δα/2)
- 左转（deflection > 0）→ 逆时针弧；右转 → 顺时针弧
- 里程 = 实际几何长度累加，保证每段 endMileage === 下一段 startMileage
- 内置 Vec2 工具函数（sub/add/scale/len/normalize/cross/dist），不依赖第三方库
